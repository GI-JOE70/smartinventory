# SmartInventory

SmartInventory is a Flutter app that helps users track and manage inventory in one place. It replaces spreadsheets and manual stock counts with a simple mobile workflow for adding products, monitoring stock levels, and staying on top of low-stock items.

## Features

- Add, edit, and delete inventory items
- Track stock quantities in real time
- Low-stock alerts and status indicators
- View detailed product information
- Categorized product images (Bakery, Dairy, Groceries, etc.)
- Simple and clean user interface

## Tech Stack

- **Framework:** Flutter
- **Language:** Dart
- **Storage:** Local storage
