# SmartInventory

SmartInventory is a **[Flutter / React Native / Android]** app that helps users track and manage inventory in one place. It replaces spreadsheets and manual stock counts with a simple mobile workflow for adding products, monitoring stock levels, and staying on top of low-stock items.

## Features

- Add, edit, and delete inventory items
- Track stock quantities in real time
- Low-stock alerts and status indicators
- Search, filter, and sort products
- Dashboard summary of inventory status
